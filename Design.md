Team Grid — Stitch Design System

Design Authority
Google Stitch is the primary tool for generating and iterating UI designs. However, all generated screens must follow the design principles below.

Product Personality
Team Grid should feel: Professional, Intelligent, Modern, Calm, Collaborative, Premium.
It should not feel like a generic AI-generated dashboard.

Visual Direction
Use: Clean layouts, Strong information hierarchy, Generous whitespace, Subtle borders, Clear data visualization, Minimal visual noise.

Color Direction
Primary: Deep Indigo (#4F46E5)
Background Light: #F8F9FB
Background Dark: #0B0D12
Status: Green (Success/On Track), Amber (Warning), Red (Risk/Error), Indigo (Active/Primary action), Gray (Neutral)

Typography
Primary font: Inter
H1 → Page title
H2 → Major sections
H3 → Cards / groups
Body → Normal content
Small → Metadata

Stitch Prompt Requirements
Every Stitch prompt should specify: Product name, Screen purpose, Target user, Important information, Required actions, Responsive requirements, Design style.
